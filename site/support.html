My Thingino camera doesn't show up

Your phone and the camera need to be on the same Wi-Fi. Thingino cameras announce themselves on the network, so they normally appear within a few seconds. If yours doesn't, tap the plus button and type the camera's IP address.

Which password do I use for Thingino?

Use the password for the camera's web page, the one you log in with as root. CamFetti uses it once to create an API key and then forgets it.

Adding another brand

Type the camera's IP address with its username and password. CamFetti tries ONVIF first and then the usual stream addresses for Reolink, Hikvision, Dahua and Tapo. If that doesn't work, paste the full rtsp:// link from the camera's manual.

Watching away from home

Install Tailscale on your phone and on a computer or server at home that can see your cameras. Then open a camera's details in CamFetti and add its Tailscale address under Away from Home. CamFetti tries the home address first and switches automatically.

Stock Wyze cameras

Wyze's own firmware doesn't offer a standard video stream. Flash the camera with Thingino or run docker-wyze-bridge, and then add it like any other camera.
